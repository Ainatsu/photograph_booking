# 约拍移动端

这是一个独立于现有桌面前端的移动端应用，技术栈为 **Ionic Vue + Capacitor + TypeScript**。它复用项目现有 FastAPI 接口，但拥有完全针对 Android 手机设计的页面、导航和交互。

当前代码已经包含：

- “发现 / 橱窗 / ＋发布 / 消息 / 我的”五入口底部导航
- 发现页：作品瀑布流、摄影师列表、搜索、下拉刷新、骨架屏、错误重试与空状态
- 橱窗页：摄影方案、公开企划、搜索与接口回退
- 作品、摄影师、方案、企划详情页，以及携带引用内容的咨询入口
- 真实账号注册、登录、会话恢复、登录失效处理与退出登录
- 真实个人资料展示、客户进行中订单统计与摄影师身份识别
- 个人资料与账号安全：昵称、简介、头像、主页封面、公开邮箱、邮箱/手机号验证、修改密码与退出全部设备
- 摄影师认证：首次申请、审核中只读状态、资料更新、驳回意见、旧材料预填、作品保留/移除/新增和通过后经营入口
- 从摄影师/套餐详情进入预约，读取服务端真实档期并创建订单
- 客户与摄影师订单队列、状态筛选、下拉刷新和下一步提示
- 摄影师确认/拒绝预约、开始服务；客户完成演示支付和确认验收
- 可深链访问的订单详情页、完整进度、责任方提示、合同快照和事件时间线
- 双方改期申请、接受/拒绝/撤回/反提时间，以及带原因确认的订单取消
- 摄影师多版本作品交付、客户文件预览/下载、免费返修申请与返修排期
- 客户确认验收和 1–10 分订单评价，关键请求带加载、错误和幂等重试保护
- 订单争议发起、图片举证、补充材料、平台处理进度与履约冻结提示
- 真实联系人、会话深链、引用卡片、订单事件、未读角标和 WebSocket 实时消息
- 真实通知中心：全部/未读筛选、单条/批量已读、未读角标、订单/企划深链和 WebSocket 实时提醒
- 企划、摄影作品和摄影方案的真实发布表单、本机文字草稿与媒体上传进度
- 摄影师提交、修改和撤回企划应邀方案，客户比较候选并选定摄影师生成订单
- “企划与应邀”管理中心：按状态查看我的企划/我的应邀、下拉刷新和结果空状态
- 移动端企划编辑、现有参考图保留/移除、草稿发布、过期企划重新发布与关闭确认
- 摄影方案管理中心：完整列表、编辑、现有样片保留/移除、上下架与删除确认
- 摄影师档期与服务能力：服务地区、器材、风格、预约规则、单日/区间排期及快捷批量设置
- 作品与摄影方案收藏、摄影师关注、关注/粉丝列表及账号同步
- 作品与摄影方案点赞、公开评论、评论分页，以及个人“赞过的作品”列表
- Android 安全区、48dp 触控区域、系统返回栈和 reduced-motion 支持
- 本地浏览器代理，以及 Android 模拟器/真机 API 地址配置

## 在电脑上边开发边测试

完全可以，不需要先上传服务器。

### 1. 启动本地 FastAPI

在项目根目录运行：

```powershell
python -m uvicorn backend.app.main:app --reload --host 0.0.0.0 --port 8000
```

API 文档位于 <http://127.0.0.1:8000/docs>。

### 2. 启动移动端网页开发服务器

```powershell
cd mobile-app
npm install
npm run dev
```

打开 <http://127.0.0.1:5175>，使用 Chrome/Edge 开发者工具的手机设备模式即可实时调试。Vite 会把 `/api`、`/static` 和 `/ws` 代理到本机 8000 端口，所以浏览器阶段不用修改后端地址。

### 3. 运行检查

```powershell
npm run typecheck
npm test
npm run build
```

## Android 调试

首次安装 Android Studio，并确认上面的类型检查、测试和 Web 构建均通过后，在本目录运行：

```powershell
npx cap add android
npm run build
npm run cap:sync
npm run android
```

### Android 模拟器连接本机后端

复制 `.env.example` 为 `.env.local`，把地址改为：

```env
VITE_API_BASE_URL=http://10.0.2.2:8000/api/v1
VITE_ASSET_BASE_URL=http://10.0.2.2:8000
```

`10.0.2.2` 是 Android 官方模拟器访问宿主电脑的固定地址。

本地后端是 HTTP，因此同步 Android 工程前还要临时允许本地明文流量：

```powershell
$env:CAPACITOR_LOCAL_HTTP='true'
npm run cap:sync
```

正式打包连接 HTTPS API 时不要设置这个环境变量，工程会恢复禁止明文与混合内容。

### 真机连接本机后端

手机与电脑连接同一局域网，把上面的 `10.0.2.2` 换成电脑的局域网 IP，例如 `192.168.1.20`。FastAPI 必须使用 `--host 0.0.0.0` 启动，并确保 Windows 防火墙允许 8000 端口的局域网访问。

## 目录约定

```text
src/
├─ api/          FastAPI 客户端与公开数据接口
├─ components/   移动端通用组件
├─ layouts/      五入口应用壳
├─ pages/        一级页面与详情页
├─ theme/        品牌 tokens 与全局移动端样式
├─ types/        API 数据类型
└─ utils/        媒体地址和展示格式工具
```

移动端不依赖 Element Plus，也不直接复用桌面页面；只共享后端业务能力和数据结构。这样可以保持手机体验完整，同时避免维护两套业务规则。
