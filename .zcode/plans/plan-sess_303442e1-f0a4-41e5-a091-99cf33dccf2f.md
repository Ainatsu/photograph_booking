# 阶段 E（第一部分）：search_then_inspire 迁移到 Workflow Runtime

范围（已确认）：仅迁移 `search_then_inspire` 固定流程；预订流程与 `waiting_user` 确认接入留待后续会话。模式完全复刻阶段 D 的 `image_appreciation_and_search` 参考实现。

## 目标链路

```text
intent=compound_workflow（flag 开启时）
  -> workflow run（search_then_inspire）
  -> step "search"：portfolio.search（复用现有 capability）
  -> step "inspire"：inspiration.generate（新 capability，包装 create_inspiration_workflow）
  -> run.result 即最终回复 {content, metadata}（inspire 是最后一步，无需 compose）
```

## 新增文件

**1. `backend/app/services/agent_workflow_search_then_inspire.py`**（镜像 appreciation_search 模块结构）
- `WORKFLOW_TYPE_SEARCH_THEN_INSPIRE = "search_then_inspire"`
- `build_search_then_inspire_plan()`：两步 DAG
  - `search`：capability `portfolio.search`，context_key `search`，input_template `{query_text: "$input.content", city: "$input.search.city", styles: "$input.search.styles", budget_min: "$input.search.budget_min", budget_max: "$input.search.budget_max", limit: "$input.search.limit", exclude_resource_ids: "$input.search.exclude_resource_ids"}`（wrapper 保证 `input.search` 各键必定存在，None/[] 合法，避免模板 fail-closed）
  - `inspire`：capability `inspiration.generate`，depends_on `["search"]`，input_template `{reference_text: "$input.content", items: "$context.search.items"}`
- `run_search_then_inspire_workflow(db, *, user_id, conversation_id, message_id, content, intent_slots, exclude_resource_ids, turn_id=None) -> {content, metadata}`：
  - run input 归一化：`{"content": content or "", "search": {city/styles/budget_min/budget_max/limit/exclude_resource_ids 从 intent_slots 归一（默认 None/[]/3）}}`
  - create_workflow_run → 镜像事件 → run_workflow → 再镜像（复用共享 helper，见 §3）
  - 审计对齐：best-effort 调用 `log_retrieval_run`（retrieval payload 取自 `$context.search` 的 retrieval 字段，try/except 包裹，同 legacy 4065-4081 行为）
  - `_result_from_run`：
    - completed → inspire 结果 data（create_inspiration_workflow 的 content/metadata）+ 附加 metadata：`task_plan`（用 `TaskPlan`/`TaskStep` 构造 legacy 兼容快照：search completed 带 count/resource_ids，inspire 状态取 run 终态）、`workflow_sources`（search items 的 id/title 对）、`workflow` 引用（`agent_workflow_ref_v1`）
    - failed 且 error code = `no_usable_images` → legacy 固定文案「没有找到包含可用静态图片的匹配作品，请调整风格、城市或预算后重试。」+ task_plan + workflow_status（与 4296 行逐字一致）
    - 其余失败 → 降级文案 + workflow 引用 + degraded_reason（同阶段 D 模式）

**2. `backend/app/services/agent_workflow_event_mirror.py`**
- 从 `agent_workflow_appreciation_search.py` 抽出 `_mirror_new_events`（含 `WORKFLOW_EVENT_MIRROR_SCHEMA_VERSION`），改为公开函数；appreciation 模块改为 import（行为不变，阶段 D 测试覆盖回归）

**3. 契约与 adapter（沿用阶段 A 模式，在现有文件内追加）**
- `ai_capability_contracts.py`：`InspirationGenerateInput {reference_text: str, items: list[dict]}`、`InspirationGenerateData {schema_version, status, content, inspiration_id?, entry?, error?}`
- `ai_capability_adapters.py`：`inspiration_generate` adapter：
  - 复刻 legacy 4260-4278 的可用图过滤（跳过 video/无 url，取前 12，构造 trusted_images，`provider_image_url` 经惰性 import `ai_service._image_url_for_provider`，同 `_provider_messages` 的防循环导入模式）
  - 空可用图 → 返回 failed 信封数据（error code `no_usable_images`，不可重试）
  - 有图 → 调用 `create_inspiration_workflow(db, user_id=context["user_id"], conversation_id=context["conversation_id"], message_id=context["message_id"], reference_text=..., images=trusted_images)`，把返回的 content/metadata 装进 data
- `ai_capability_registry.py`：注册 `inspiration.generate`（kind=tool，retryable=False，timeout 30s，idempotent=True——内部沿用 `inspiration-draft:{task.id}` 幂等键，与 legacy 一致）
